UX-1.1 — установка
=================

1. Остановите AI Bodhi, если он запущен.
2. Распакуйте архив в корень проекта Lotus-AI-Manager-v0.5.
3. Подтвердите замену существующих файлов.
4. Активируйте окружение:

   .venv\Scripts\activate.bat

5. Запустите проверки:

   python -m pytest -q
   python tools\ux_1_1_diagnostics.py
   python tools\ux_1_1_smoke.py
   python tools\ux_1_1_report.py

Ожидаемый результат pytest: 325 passed.

Ручная проверка:
- «В Тибет возите?» — карточка тура с фото и очищенным описанием.
- «Что входит?» — ответ относится к последнему показанному туру.
- «Колокольчик имеется?» — поиск только по товарам, без показа туров.
