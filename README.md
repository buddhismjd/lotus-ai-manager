# Lotus AI Manager v0.5

Главное изменение: если клиент спрашивает про направление, страну, Кайлас, Лапчи, Непал, Тибет, Бутан, поездку или тур, бот ищет только по страницам с типом `tour` и показывает ссылку на страницу тура.

## Запуск
1. Остановите старый сервер: Ctrl + C.
2. Запустите `setup.bat`.
3. Запустите `run.bat`.
4. Откройте `http://127.0.0.1:8000/admin`.
5. Нажмите «Обновить сайт».
6. Проверьте в чате: «Есть тур на Кайлас?», «Что есть по Лапчи?», «Хочу в Непал».
