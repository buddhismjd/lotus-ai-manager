- Добавлено извлечение UID товаров непосредственно из HTML страниц категорий.

- Добавлено присвоение категорий по реальному источнику товара.
- Проверка полноты учитывает недоступные обязательные страницы.
- Добавлены diagnostic, smoke и report tools.
