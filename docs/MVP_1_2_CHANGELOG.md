# MVP-1.2 Changelog

- Расширены устойчивые признаки путешествия в Dynamic Query Router.
- Запросы с «корой», «съездить», «ехать», «поехать», «возите» направляются в Tour Intelligence.
- Добавлена регрессия против ошибочного выбора товаров по географическому совпадению.
- Подтверждено, что явные товарные запросы с географией остаются товарными.
- Добавлены diagnostic, smoke и report tools.
