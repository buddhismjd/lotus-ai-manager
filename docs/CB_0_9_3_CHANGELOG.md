# CB-0.9.3 Changelog

- Добавлена централизованная политика благородного и тёплого языка.
- Смягчены формулировки карточек, отсутствующих цен, дат, контактов и заявок.
- Добавлена добровольная кнопка «Отправить информацию на email».
- Добавлена отдельная стадия диалога для ввода и проверки email.
- Email сохраняется с предметом интереса и контекстом разговора в существующей таблице `leads`.
- Добавлены регрессионные тесты, diagnostic, smoke и report tools.
