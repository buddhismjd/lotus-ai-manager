# CB-1.3.0 — Live Widget Integration

The widget is aligned with the current Svet Lotosa website visual language:
navy `#123456`, light airy surfaces, rounded buttons and restrained decorative geometry.

Implemented:
- responsive desktop and mobile presentation;
- persistent session restore;
- explicit new-dialog reset;
- quick entry actions for travel, shop and consultation;
- rich cards for tours and products;
- network and accessibility states;
- Tilda T123 production embed template.

Production requires an HTTPS-accessible backend domain. Replace `YOUR-API-DOMAIN`
in `widget/tilda_embed.html` only after the backend is deployed.
