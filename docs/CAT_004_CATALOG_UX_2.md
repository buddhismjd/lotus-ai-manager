# CAT-004 — Catalog UX 2.0

## Цель

Каталожный запрос возвращает полную релевантную подборку, а не одну случайную карточку. Географический фильтр тура является строгим и не заменяется полным каталогом.

## Контракт

API `/api/sales/chat` и `/api/bodhi/chat` могут возвращать поле `items`. Каждый элемент содержит безопасные данные карточки: название, URL, изображение, цену, наличие, материал, размер и статус.

## Товары

`backend/catalog/collection_builder.py` строит коллекцию по семантике запроса и профилям товаров. Изображение извлекается из синхронизированного поля `Изображение:` в описании до отдельной миграции медиаданных.

## Туры

`backend/tours/collection_builder.py` извлекает страну и возвращает только опубликованные туры этой страны. При отсутствии опубликованных программ проверяются планируемые туры. Полный каталог не используется как fallback для запроса с географическим фильтром.
