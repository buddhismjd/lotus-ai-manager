# CB-1.5 — Rich Cards 2.0

Rich Cards 2.0 introduces a versioned, unified presentation contract without expanding chat cards into full commercial pages.

## Backend contract

Each public card keeps the established fields and adds:

- `card_version: "2.0"`;
- `actions`: deterministic link actions generated by the backend.

Descriptions, dimensions, materials and lead-capture forms remain on canonical site pages.

## Widget renderer

The widget uses one `appendCard(item, collection)` renderer for products, tours and services. Type-specific differences are limited to:

- a visible type badge;
- honest metadata labels;
- the backend-provided action label.

Legacy `url` and `button_label` remain supported as a fallback during migration.
