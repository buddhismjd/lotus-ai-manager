# CB-1.8.0 — Deterministic Recommendation Engine

AI Bodhi now distinguishes literal catalog searches from broad commercial
selection requests.

Supported selection purposes:

- gift;
- home altar.

Recommendations are based only on evidence already present in product catalog
records. A broad recommendation returns at most six ranked products. Explicit
requests to show all matching offers are never truncated, including
aspect-centered searches such as “all products with Kalachakra”.

The engine does not recommend Buddhist practices and does not introduce an
encyclopedic answer path. The CB-1.7.0 minimal commercial-card contract remains
unchanged.
