# SDM-3 — Lead Capture Workflow

## Цель

Перевести диалог в управляемый режим оформления заявки до запуска нового поиска.

## Этапы

`discovery → lead_name → lead_contact_method → lead_contact_value → lead_complete`

Готовая заявка сохраняется в существующей таблице `leads`. Контекст выбранного тура сохраняется в поле `interest`.

## Безопасность

- поиск отключается на время заполнения заявки;
- контакт проверяется перед сохранением;
- пользователь может отменить оформление;
- отсутствующие данные не придумываются.
