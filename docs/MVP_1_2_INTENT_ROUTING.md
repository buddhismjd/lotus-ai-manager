# MVP-1.2 — Sales Intent Routing

## Цель

Не допускать выбора товара только потому, что товар и тур содержат одно географическое слово.

## Архитектурное правило

Маршрутизация выполняется до выбора карточки каталога. Явные действия путешествия имеют приоритет над совпадениями в товарных описаниях:

- съездить;
- ехать / поехать;
- возите / везёте;
- кора;
- паломничество;
- путешествие;
- поход.

Явный тип товара сохраняет приоритет для товарного запроса. Например, «чётки из Тибета» остаются товаром.

## Поток

Пользовательский запрос → смысловой контекст → тип каталога → ранжирование внутри выбранного каталога → форматирование ответа.

## Безопасность

Изменение расширяет существующий Dynamic Query Router. Отдельный параллельный маршрутизатор не создаётся.
