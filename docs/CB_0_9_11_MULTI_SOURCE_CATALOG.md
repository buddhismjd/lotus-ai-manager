# CB-0.9.11 — Multi-Source Catalog Synchronizer

## Цель

Проверять не только один Store Block Tilda, а главный магазин и все настроенные страницы товарных категорий.

## Источники

- Все товары
- Статуи
- Подвески
- Серьги
- Малы (чётки)
- Гау
- Благовония

Список хранится в `backend/config/product_catalog_sources.json` и расширяется конфигурацией, без специальных условий в коде.

## Алгоритм

1. Загрузить каждую страницу-источник.
2. Извлечь товарные UID из ссылок и data-атрибутов Tilda.
3. Обнаружить Store Block страницы.
4. Загрузить все страницы Store API каждого уникального блока.
5. Объединить товары по UID.
6. Присвоить категорию по странице-источнику.
7. Считать каталог полным только если все обязательные источники доступны и все Store Block загружены полностью.

## Безопасность

Если обязательная страница категории не загрузилась, проверка завершается ошибкой. Нулевое количество ссылок отображается в отчёте и не скрывается.
