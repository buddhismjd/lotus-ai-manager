# Руководство разработчика

## Окружение

- Windows 11
- Python 3.12
- SQLite
- FastAPI/Uvicorn
- локальный запуск без Docker

Активация окружения:

```cmd
.venv\Scripts\activate.bat
```

## Запуск

```cmd
setup.bat
run.bat
```

## Порядок обработки запроса

Публичная точка входа:

```python
backend.services.bodhi_service.answer_query()
```

Приоритет:

1. товары;
2. активные туры;
3. планируемые туры;
4. ответы по аспектам;
5. legacy Knowledge Answer;
6. Semantic Engine;
7. fallback.

Semantic Engine не должен перехватывать:

```text
У вас есть Ваджра?
Статуя Белой Тары
Поход в Лапчи
Есть поездка в Непал?
```

Он предназначен для:

```text
Расскажи про Ваджру
Какие практики связаны с Миларепой?
Что связано с Белой Тарой?
```

## Терминология

Во внешнем интерфейсе:

- «аспект», не «сущность»;
- «тип аспекта»;
- «предмет для практики»;
- «направление» для путешествий.

Канонические типы:

```text
Белая Тара      → Бодхисаттва
Зелёная Тара    → Бодхисаттва
Ченрезиг        → Бодхисаттва
Дзамбала        → Бодхисаттва
Ваджрасаттва    → Бодхисаттва
Ушнишавиджая    → Бодхисаттва
Миларепа        → Учитель
Гуру Ринпоче    → Учитель
Махакала        → Защитник
Гаруда          → Защитник
Ваджра          → Предмет для практики
Пхурба          → Предмет для практики
```
