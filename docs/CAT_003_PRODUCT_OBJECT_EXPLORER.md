# CAT-003 — Product Object Explorer

## Цель

Построить подтверждённую карту структуры сохранённых Tilda `product`-объектов по всему каталогу. Инструмент работает с таблицей `product_raw_snapshots` и не обращается к Tilda повторно.

## Архитектура

```text
product_raw_snapshots
        ↓
recursive schema explorer
        ↓
field coverage + schema tree + catalog statistics
```

Explorer не изменяет raw snapshots и не записывает значения в нормализованный каталог. Его результаты предназначены для последующих резолверов категории, наличия и атрибутов.

## Артефакты

Формируются в `data/product_object_explorer/`:

- `field_coverage.json` — количество товаров, содержащих каждый путь, типы и примеры;
- `schema_tree.json` — рекурсивное дерево структуры;
- `catalog_statistics.json` — сводка по `characteristics`, `properties`, `editions` и верхнеуровневым полям.

## Правила

- неизвестные поля сохраняются автоматически;
- пустой массив фиксируется как существующее поле, но дочерние пути не выдумываются;
- некорректный raw JSON не останавливает анализ остальных товаров и отображается диагностикой;
- никакие значения не интерпретируются как категория, материал, размер или наличие на этом этапе.
