# CAT-004.1 — Collection compatibility and catalog media

## Цель

Завершить Catalog UX 2.0 без регрессий диалоговых сценариев и подключить структурированные изображения каталога к карточкам подборок.

## Архитектурные решения

- Коллекции товаров формируются после специальных сценариев выбора статуй и тханок, email-consent и artisan workflow.
- Строгая коллекция туров по стране выполняется только для общего поиска направления. Запросы цены, даты и подробностей сохраняют прежний маршрут обработки.
- `SalesReply.items` расширяет прежний контракт ответа и не заменяет `suggestions`, URL-кнопки или dialogue state.
- Изображение берётся прежде всего из `Product.image_url`, заполненного таблицей `product_catalog_items`. Текстовое поле `Изображение:` остаётся совместимым fallback.
- Для обновления изображений используется существующий verified synchronizer, а не отдельный обходной парсер.

## Обновление данных

```cmd
REFRESH_CATALOG_MEDIA.bat
```

Команда выполняет verified product catalog sync, обновляет Product Profiles и запускает collection report. В отчёте для карточек должно отображаться `image=True`.

## Регрессия

Проверяются:

- все товары по аспекту возвращаются одной подборкой;
- структурированный `image_url` попадает в rich card;
- статус наличия сохраняется без подмены;
- URL-кнопки, email workflow и artisan workflow не перехватываются Collection Engine;
- фильтр страны не подменяет цену, дату или подробности тура.
