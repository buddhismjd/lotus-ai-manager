# SDM-1 Changelog

- Добавлен типизированный `NextActionType`.
- Добавлены `DialogueSuggestion`, `DialoguePlan` и `SalesDialogueManager`.
- `/api/sales/chat` возвращает `next_action` и `suggestions`.
- Локальный `/chat-ui` показывает быстрые кнопки продолжения.
- Вопрос о неизвестной стоимости тура получает честный специализированный ответ.
- Добавлены regression, diagnostic, smoke и report tools.
