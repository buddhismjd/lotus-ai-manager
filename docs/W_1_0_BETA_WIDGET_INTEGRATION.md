# W-1.0 — Beta Widget Integration

## Цель

Подготовить собственный виджет AI Bodhi к закрытому тестированию на сайте `https://svet-lotosa.tilda.ws`.

## Реализовано

- виджет и его ресурсы отдаются самим FastAPI;
- Tilda-вставка доступна по `/widget/embed`;
- добавлен публичный health-check `/widget/health`;
- поддерживается восстановление и сброс сессии;
- запросы имеют тайм-аут и кнопку повторной отправки;
- карточки не содержат описаний;
- кнопки карточек соответствуют типу: товар, тур, услуга;
- ошибки загрузки изображений не ломают карточку;
- CORS уже разрешает `https://svet-lotosa.tilda.ws`.

## Архитектура

Tilda загружает HTML/CSS/JS виджета с HTTPS-домена FastAPI. Виджет обращается к `/api/sales/chat`, а ядро AI Bodhi остаётся независимым от Tilda.

## Ограничение закрытой беты

Локальный адрес `127.0.0.1` недоступен посетителям сайта. Перед вставкой в Tilda FastAPI нужно опубликовать через HTTPS-туннель или сервер. Для теста подходит временный HTTPS-туннель.
