# Lotus AI Manager

## Цель

AI-менеджер для сайта https://svet-lotosa.tilda.ws

Работает локально на Windows.

Основные функции:

- консультации клиентов
- подбор туров
- ответы только по базе знаний
- сбор заявок
- передача менеджеру
- чат-виджет для Tilda
